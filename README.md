# Bank Management System

A complete banking solution built with Flask and MySQL for college DBMS projects.

## Features

- ✅ Customer Registration & Authentication
- ✅ Admin Dashboard
- ✅ Account Management (Savings, Checking, Fixed Deposit)
- ✅ Deposit, Withdraw, Transfer Operations
- ✅ Transaction History
- ✅ Loan Application & Management
- ✅ Reports & Analytics
- ✅ Responsive UI

## Tech Stack

- **Backend**: Python Flask
- **Database**: MySQL 8.0
- **Frontend**: HTML5, CSS3, JavaScript
- **Authentication**: Flask-Login

## Quick Start

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Setup MySQL database: Run `database/schema.sql`
4. Configure `app/config.py` with your MySQL credentials
5. Run: `python run.py`
6. Open: [localhost](http://localhost:5000)
